Issues relating to Windows OneDrive

If you are a windows user: please expand the following warning!
OneDrive is used by many institutions to sync your user folder (C:\Users\[your-username]\) within an organisation. It may cause issues with the installation of the computing environment we will use in our course. The sync mechanism basically stores the files in a different location to C:\Users\[your-username]\, which is hard to find.
If you have OneDrive set up, please ensure that you can access your C:\Users\[your-username]\Downloads folder:

  • Open File Explorer
  • Right click on the "Downloads" folder in the left-hand navigation pane
  • Select "Properties"
  • In the "Location" tab, ensure that the path is set to C:\Users\[your-username]\Downloads

If you encounter problems, please contact your IT support team and workshop organisers for assistance before the workshop.
